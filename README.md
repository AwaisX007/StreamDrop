# StreamDrop v1
### Download videos in seconds
**Made and developed by Marineo**

---

## Requirements

Before running StreamDrop, you need to add two free tools to the `bin` folder manually. StreamDrop does not include them due to file size.

- **yt-dlp** — https://github.com/yt-dlp/yt-dlp/releases/latest → download `yt-dlp.exe`
- **ffmpeg** — https://ffmpeg.org/download.html → download the Windows build, grab `ffmpeg.exe` from the `bin` folder inside

---

## Installation

1. Extract the `.7z` archive anywhere you want (Desktop, C drive, etc.)
2. Open the extracted `StreamDrop V1` folder
3. Open the `bin` folder inside it
4. Place `yt-dlp.exe` and `ffmpeg.exe` into the `bin` folder
5. Go back to the `StreamDrop V1` folder and run `StreamDrop.exe`

Your folder should look like this:

```
StreamDrop V1/
├── StreamDrop.exe
├── bin/
│   ├── yt-dlp.exe
│   └── ffmpeg.exe
├── locales/
├── resources/
└── ...
```

---

## How to Use

1. Paste a video or playlist URL into the URL field
2. Choose your format (Video, Audio, Playlist, etc.)
3. Select your quality
4. Choose where to save the file
5. Hit **Download**

Supported sites include YouTube, Twitter/X, TikTok, Instagram, and hundreds more via yt-dlp.
