# Changelog

## 3.0.0 - 2026-08-11

- Added simple video, audio, subtitle, clip, and playlist download workflows.
- Added URL analysis, exact-format selection, batch input, queue progress,
  cancellation, retries, history, and completed-file actions.
- Added persisted quality, naming, metadata, subtitle, concurrency, rate-limit,
  archive, cookies, chapter, and SponsorBlock preferences.
- Added verified, asynchronous installers for official yt-dlp releases and the
  Gyan.dev FFmpeg release-essentials package.
- Added black-and-gold navigation with dedicated History, Settings, Tools, and
  About areas.
- Added workspace-local development scripts and compact Windows NSIS packaging.
